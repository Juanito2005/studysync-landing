# StudySync - Landing Page Optimizada (SPA) 🚀

## 📖 Descripción del Proyecto
[cite_start]Este repositorio contiene el desarrollo de una Single Page Application (SPA) para **StudySync**, una aplicación ficticia de gestión de rutinas de estudio[cite: 6]. 

[cite_start]El objetivo principal de este proyecto es aplicar técnicas avanzadas de Posicionamiento y Optimización Web (SEO) [cite: 2][cite_start], adaptando el contenido no solo para motores de búsqueda tradicionales, sino también para modelos de Inteligencia Artificial (IA-Friendly)[cite: 7].

## ✨ Requisitos Técnicos Implementados

A lo largo del código (`index.html`), se han aplicado las siguientes capas de optimización:

### [cite_start]1. SEO On-Page [cite: 9]
- [cite_start]Etiquetas `<title>` (55-60 caracteres) y `<meta description>` optimizadas con llamadas a la acción (CTA)[cite: 11, 12].
- [cite_start]Implementación de Canonical URL para evitar penalizaciones por contenido duplicado[cite: 15].
- [cite_start]Integración de etiquetas **Open Graph** y **Twitter Cards** para previsualización enriquecida en redes sociales[cite: 17, 19].
- [cite_start]Configuración de Favicons y Apple Touch Icons[cite: 16].

### [cite_start]2. Contenido SEO Estructurado [cite: 20]
- [cite_start]Jerarquía semántica de encabezados (`<h1>`, `<h2>`, `<h3>`) con palabras clave integradas[cite: 22, 23, 24].
- Maquetación con **Bootstrap 5** para un diseño *responsive* y moderno (Dark/Tech Theme) sin perder la estructura semántica de HTML5.

### [cite_start]3. Integración de IA (IA-Friendly) [cite: 35, 36]
- [cite_start]**Textos fragmentables:** Uso de listas semánticas y tarjetas descriptivas para facilitar la extracción de *features* por parte de LLMs[cite: 39, 40].
- [cite_start]**Tablas de datos estructurados:** Inclusión de una tabla comparativa clara entre StudySync y otras metodologías[cite: 37].
- [cite_start]**Sección FAQ estructurada:** Preguntas y respuestas frecuentes utilizando las etiquetas `<details>` y `<summary>`[cite: 38].

### [cite_start]4. SEO Técnico y Datos Estructurados (Schema) [cite: 27]
- [cite_start]Inyección de código **JSON-LD** en el `<head>` y el `<body>`[cite: 28].
- [cite_start]Uso de múltiples esquemas de Schema.org: `Organization`, `SoftwareApplication`, `FAQPage` y `ContactPage`[cite: 29, 30].

### [cite_start]5. Accesibilidad [cite: 31]
- [cite_start]Navegación clara mediante menú *sticky* con *smooth scroll* (enlaces ancla)[cite: 32, 44].
- [cite_start]Formularios accesibles con correcta vinculación de `<label>` e `<input>`, además de atributos `aria-required` y `aria-label` en enlaces de iconos[cite: 34].

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura semántica.
- [cite_start]**Bootstrap 5 (CDN):** Estilos, sistema de rejilla y componentes UI[cite: 46].
- [cite_start]**JSON-LD:** Marcado de datos estructurados para SEO Técnico[cite: 28].

## 🚀 Cómo ejecutar el proyecto
[cite_start]El proyecto no requiere de ningún entorno de servidor adicional ni instalación de dependencias[cite: 49].
1. Clona este repositorio.
2. [cite_start]Abre el archivo `index.html` directamente en cualquier navegador web moderno[cite: 49].
