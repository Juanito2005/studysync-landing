# StudySync - Landing Page Optimizada (SPA) 🚀

## Descripción del Proyecto
Este repositorio contiene el desarrollo de una Single Page Application (SPA) para **StudySync**, una aplicación ficticia de gestión de rutinas de estudio.

El objetivo principal de este proyecto es aplicar técnicas avanzadas de Posicionamiento y Optimización Web (SEO), adaptando el contenido no solo para motores de búsqueda tradicionales, sino también para modelos de Inteligencia Artificial (IA-Friendly).

## Requisitos Técnicos Implementados

A lo largo del código (`index.html`), se han aplicado las siguientes capas de optimización:

### 1. SEO On-Page:
- Etiquetas `<title>` (55-60 caracteres) y `<meta description>` optimizadas con llamadas a la acción (CTA).
- Implementación de Canonical URL para evitar penalizaciones por contenido duplicado.
- Integración de etiquetas **Open Graph** y **Twitter Cards** para previsualización enriquecida en redes sociales.
- Configuración de Favicons y Apple Touch Icons.

### 2. Contenido SEO Estructurado:
- Jerarquía semántica de encabezados (`<h1>`, `<h2>`, `<h3>`) con palabras clave integradas.
- Maquetación con **Bootstrap 5** para un diseño *responsive* y moderno (Dark/Tech Theme) sin perder la estructura semántica de HTML5.

### 3. Integración de IA (IA-Friendly)
- **Textos fragmentables:** Uso de listas semánticas y tarjetas descriptivas para facilitar la extracción de *features* por parte de LLMs.
- **Tablas de datos estructurados:** Inclusión de una tabla comparativa clara entre StudySync y otras metodologías.
- **Sección FAQ estructurada:** Preguntas y respuestas frecuentes utilizando las etiquetas `<details>` y `<summary>`.

### 4. SEO Técnico y Datos Estructurados (Schema):
- Inyección de código **JSON-LD** en el `<head>` y el `<body>`.
- Uso de múltiples esquemas de Schema.org: `Organization`, `SoftwareApplication`, `FAQPage` y `ContactPage`.

### 5. Accesibilidad
- Navegación clara mediante menú *sticky* con *smooth scroll* (enlaces ancla).
- Formularios accesibles con correcta vinculación de `<label>` e `<input>`, además de atributos `aria-required` y `aria-label` en enlaces de iconos.

## Tecnologías Utilizadas
- **HTML5:** Estructura semántica.
- **Bootstrap 5 (CDN):** Estilos, sistema de rejilla y componentes UI.
- **JSON-LD:** Marcado de datos estructurados para SEO Técnico.

## Cómo ejecutar el proyecto
El proyecto no requiere de ningún entorno de servidor adicional ni instalación de dependencias.
1. Clona este repositorio.
2. Abre el archivo `index.html` directamente en cualquier navegador web moderno.
